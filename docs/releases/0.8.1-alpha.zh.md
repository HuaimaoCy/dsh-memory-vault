# Alaya 0.8.1Alpha — Glass&New UI-preview

此版本为 Windows x64 预览版，包内合法版本号为 `0.8.1-alpha`，界面显示为 `0.8.1Alpha`。发布到 GitHub 的 prerelease，保留正式版更新通道。

- 重做玻璃合成：清晰倒角折射、方向性亮暗反光与中央磨砂分层。去掉均匀发光描边，保留纯白背景上的曲面边界。
- 背景改为纯白，正文卡片改用浅灰，以接触阴影与柔和投影区分层次。
- 选中态统一为低对比透镜；分段控件支持按住鼓起、拖动放大预览、释放提交和弹簧回落。键盘和减少动态效果保持即时反馈。
- 外观、布局集中到设置。侧栏透明度可连续调整并保存。删除重复视图区、主界面说明和底部统计栏。
- 顶部搜索和加号略微放大，图标统一大小与视觉中线；画布和录入收进加号菜单，AI 助手和词典移至同栏。
- 自由画布铺满窗口，工具合并为底部的紧凑纯图标组；移除空画布引导框。继续支持文本、便签、笔记引用、连接、撤销与重做。
- 侧栏移除归档、物理模型和解题方法入口，加入自由画布与试卷。原有物理模型和方法记录保留在全部笔记中。
- 新增试卷编成：1–100 道题组成一张卡片，可改名、调整题序、打开原题、拆开试卷；原题内容与复习记录保留，导入导出会重建题目引用。
- 支持将卡片拖到待复习、已掌握或回收站，状态写入本地库；整张试卷可批量调整复习状态。
- 单击卡片只选中，双击或键盘打开整页专注阅读。左上返回，右上为 AI 查询、批注和编辑图标。批注与编辑结果保存到本地库。
- AI 面板从左侧展开，主界面与专注页保持相同位置。
- 修复打开笔记白屏：校验读取结果、失败时保持/恢复列表，清除专注页继承的负边距。

验证包含真实 Electron 的双击、阅读/编辑/批注/返回、左侧 AI、编卷/拆卷、拖动复习状态、画布保存竞态与坏数据恢复；浏览器验证透明度持久化、菜单、图标几何、白屏恢复、分级回退与边缘折射隔离。

玻璃与交互按公开的 Apple 设计语言实现为 Web/Electron 近似效果；不使用或声称复用 Apple 私有渲染代码。
