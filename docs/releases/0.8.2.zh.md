# Alaya 0.8.2 — 错题 PDF 排版

包内合法版本号 `0.8.2`，界面显示同名。Windows x64。

- **新增错题 PDF 导出**：三处入口——「导入 / 导出」菜单、多选批量栏、试卷阅读页；错题展开成题目，带着原图与公式一起打印。
- **自由排版**：A4 竖版 / 横版，题目块可拖动、改宽、跨页；1–2 栏自动排列，量过真实高度后再排一版，长题不压页脚。
- **显示内容可逐项开关**：原图、我的作答、参考答案、错因、复盘、学科与日期、题号；页眉页脚可改，页码固定在右下角。
- **版面会记住**：摆放位置与版式写进笔记本偏好（`prefs.pdf`），下次打开同一批题目沿用上次版面；最多 50 步撤销。
- 越界与重叠如实提示：提示条给出「超出页面下沿」「互相遮挡」的数量，不静默裁切。
- 导出走 Chromium `printToPDF`：`@page` 固定纸张、样式内联、图片按最长边 1400px 压成 JPEG 内嵌，无外部请求；单次上限 100 题 / 40 页 / 64 MB HTML。
- 打印窗口独立：不加载 preload、不开 Node、禁止弹窗与权限请求。

验证：新增纯模型测试（`tests/pdf-layout-smoke.mjs`）与真窗口测试（`tests/run-desktop-pdf.mjs`，真实 printToPDF 落盘并校验 PDF 头、页数、大小，关掉再开沿用版面）；`npm test`、`core/notebook/mistakebook/papers/canvas` 冒烟与画布真窗口套件保持通过。

已知限制：字段开关是整份文档统一设置，暂不支持逐题覆盖；自由画布不参与 PDF 导出。

实现与测试细节见 [错题 PDF 导出](../pdf-export.zh.md)。
