# Alaya 0.8.2 — 错题 PDF 排版与自由画布

包内合法版本号 `0.8.2`，界面显示同名。Windows x64。

## 错题 PDF 导出（A4 自由排版）

- 三处入口：「导入 / 导出」菜单、多选批量栏、试卷阅读页；错题展开成题目，带着原图与公式一起打印。
- A4 竖版 / 横版，题目块可拖动、改宽、跨页；1–2 栏自动排列，量过真实高度后再排一版，长题不压页脚。
- 显示内容可逐项开关：原图、我的作答、参考答案、错因、复盘、学科与日期、题号；页眉页脚可改，页码固定在右下角。
- 版面会记住：摆放位置与版式写进笔记本偏好（`prefs.pdf`），下次打开同一批题目沿用上次版面；最多 50 步撤销。
- 越界与重叠如实提示，不静默裁切；导出走 Chromium `printToPDF`：`@page` 固定纸张、样式内联、图片按最长边 1400px 压成 JPEG 内嵌，无外部请求。
- 打印窗口独立：不加载 preload、不开 Node、禁止弹窗与权限请求。

## 自由画布

- 手写支持鼠标与压感笔，含荧光笔、整笔橡皮、笔色与粗细；笔尖有跟随光标。
- 满窗点阵画布支持直接输入文字，缩放范围扩至 20%–1600%。左下缩放区只显示缩放比例与加减按钮。
- 新画布可直接输入文字，旧版便签仍能读取与编辑。移除卡片或画布可直接撤销。
- 图形：箭头、直线、圆、正方形，可改色、拖动、删除与撤销。
- 错题题目视图：卡片里展开题干、原图、作答、参考答案与错因，可自定显示范围与「显示起点」。
- 可在画布里单独编辑题目，保存到当前卡片，并恢复原题文字。
- 框选（`M`）与工具盘（右键 / `Q`）：换笔、改色、调粗细、框选、撤销重做集中在指针附近。
- A4 纸张模式（每画布最多 24 张）、导入图片（PNG/JPEG/WebP/GIF）、多选、卡片连线。
- A4 编辑时显示点阵，可导出全部纸张为 PDF，或导出当前页为 PNG、JPG。
- 撤销按「一次连续输入 / 一笔手写 / 一次擦除拖动 / 一次图形操作」计数，每次打开白板最多 60 步，可跨画布撤销。
- 保存用编辑版本号防竞态；画布坏数据时不新建、不写库、不覆盖原有内容。
- Windows 主窗口移除了原生菜单栏，避免按 Alt 时弹出菜单。

## 外观与材质

- 右上「外观」入口：深色 / 浅色 / 跟随系统、自定义强调色、本地图片背景，可重载、移除与重置。
- Liquid Glass 光学引擎：SDF → 高度场 → 法线 → Snell 折射 → 背景采样 → Fresnel 合成，SVG 与 WebGL2 两个后端、三档品质，默认启用折射。

## 其它

- Markdown 与 LaTeX 渲染完善：`cases` / `aligned` / `matrix` 环境；笔记正文样式抽成 `markdown.css`。
- 图片导入接受微信转发的 JPEG（EOI 后带 24 字节尾部），伪造尾部仍会被拒绝。
- 顶部/侧栏按压不再抖动；整理完成后的对话框清理；二级菜单精简并新增「AI 整理」。
- 产品分流构建：Alaya（统一）、Alaya Notebook、Alaya Database 三个产物与入口。

## 验证

- `npm test` 全套；`canvas-smoke`、`desktop-canvas`、`desktop-canvas-undo`、`desktop-liquid-glass`、`desktop-ui`、`desktop-pdf`、`desktop-images` 真窗口自测通过。
- 安装包为 NSIS（`Alaya-0.8.2-Setup.exe`）；另有 `Alaya-0.8.2-win-x64-portable.zip`，解压即用。

## 已知限制

- 错题排版 PDF 的字段开关按整份文档设置。自由画布的 A4 页面通过画布自己的导出入口输出。
- 画布连线是两张卡片中心之间的直虚线，不支持箭头样式或折线；每张图片最多 10 MB，每个笔记本中的画布图片合计最多 20 MB。
- 高 DPI 与窗口合成下的折射效果仍建议在真机上确认。
