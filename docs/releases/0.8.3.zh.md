# Alaya Notebook 0.8.3 · 自由画布手写与工具盘

Windows x64。桌面包与界面版本为 `0.8.3`，Git 标签为 `notebook-v0.8.3`。

## 0.8.3 的改动

- 画笔和新图形共用当前颜色，默认亮蓝。右键或按 `Q` 打开工具盘，可切换画笔、荧光笔、橡皮和图形。取色面板支持色相、饱和度、亮度和十六进制色值，可收藏最多 8 个自定义色。
- 顶栏新增框选入口，与工具盘和快捷键 `M` 一样，可以圈住并一起移动笔迹、图形、图片与卡片。新建连线入口已移除，旧连线仍可查看、导出和删除。
- 笔尖圆点保持在最后的位置，随笔色和粗细变化。手写减少重复采样，保留压感和转角。支持 WebGL 2 时，GPU 加速正在书写的笔迹，其他环境使用分段 SVG 预览。保存和导出继续使用矢量笔迹。
- 橡皮缓存旧笔迹范围并跳过离擦除轨迹较远的线段。擦除提交只移除命中的笔迹。保存前的文档校验集中在存储端，减少界面线程的重复计算。

## 前期白板改动补记

以下功能已纳入 `0.8.2` 的源码记录，操作方法见 [自由画布指南](../freeform.zh.md)。

- 满窗点阵画布支持直接键入文字、压感手写、荧光笔、整笔橡皮、笔色和粗细。旧版便签可继续编辑。平移和缩放随画布保存，缩放范围为 20%–1600%。左下角显示缩放比例和加减按钮。
- 支持绘制箭头、直线、圆和正方形，可改色、移动与删除。箭头使用较短的箭翼，绘制时带圆点预览。画布可撤销手写、擦除、图形、文字和对象移动，`Ctrl/⌘ Z` 支持跨画布。移除画布对象后可直接撤销。
- 可把保存的错题放入画布，展开题干、原图、作答、答案与错因，指定显示字段及滚动起点。在画布里编辑后，修改随卡片保存，可恢复原题。图片支持 PNG、JPEG、WebP、GIF，也兼容带有效尾部的微信转发 JPEG。
- 一张画布可切换无限模式和 A4 模式，可加至 24 张 A4。编辑时显示点阵，导出使用白底。PDF 可输出多页，PNG 和 JPG 输出当前页。
- Notebook 外观可跟随系统、使用浅色或深色，支持自定义主题色和本机图片背景。顶部与侧栏控件重新对齐，画布工具组使用清晰的玻璃边缘。外观偏好保存在本机。Windows 主窗口移除了会因 Alt 弹出的菜单栏。
- 同期的错题 PDF 自由排版、Markdown 与 LaTeX 渲染、AI 整理及产品分流构建，已记录在 [0.8.2 版本说明](0.8.2.zh.md)。

## 验证

在关闭 GPU 的 Electron 测试中，对有 55 条笔迹的画布连续执行 12 次橡皮移动，处理耗时的 P95 从约 45–60 毫秒降至 2–3 毫秒。已回读验证笔压与擦除结果，并检查跨画布撤销、A4 导出和 WebGL 2 预览。测试记录的是事件处理耗时。
