# Alaya 0.7.15

这是 `feat/notebook-mode` 分支上的独立外挂，保留 Memory Vault 的 Codex MCP、DSH、CLI 和本地 RPC。正式版 `main` 不包含笔记本。启动后默认进入笔记本；右上角带文字的「数据库 / 笔记本」按钮双向切换，软件会记住上次使用的模式，下次启动直接回到那里。

## 录入与整理

点击「新建笔记」选择类型。所有类型支持标题、图片、学科、知识点、标签、检索、复习、归档、回收站及导出。

| 类型 | 可记录的内容 |
| --- | --- |
| 错题 | 题干、作答、参考答案、错因与复习建议；支持图片和 PDF OCR，校对、拆题后导入 |
| 物理模型 | 对象与系统边界、假设、变量与单位、方程、推导、适用条件、检验和应用例题 |
| 解题方法 | 适用前提、步骤、每一步依据、完整例题、误区与替代方法 |
| 英语词汇 | 单词或短语、音标、词性、中文释义、例句、搭配、词形、用法辨析 |
| 手写笔记 | 电子手写画布：多种笔色与粗细、橡皮、撤销、清空，逐页保存为 PNG 原图 |
| 普通笔记 | 知识摘录、问题、理解、学习日志及图片 |

### 录入 · 一个对话框，三条路径

右上角「录入」把所有导入收进同一个对话框，顶部三个页签按「要得到什么」切换，不再有并列的多个入口：

- **错题 · 拆题**：选择或拖入一张图片 / PDF，识别文字、校对、预览拆题后批量导入，可随每题保存整张原图。
- **整页笔记**：一次最多 12 张照片或 PDF，逐张自动识别；每一张生成一篇独立笔记草稿（标题默认取识别首行，可修改），先用「保存为类型」选择普通笔记、物理模型或解题方法，核对后批量导入，图片保留为原图。
- **英语词汇**：拍照 / 扫描积累本与手动粘贴放在同一页，上下两段，解析规则一致（见下）。

识别逐张进行并显示进度，可随时取消；单个文件失败不影响其余页面。列表上方的「导入 / 导出」菜单提供「导出笔记本 JSON」与「导入旧版错题 JSON」。

### 积累英语词汇 · 拍照与粘贴

「录入 → 英语词汇」的拍照段把整本手写积累本逐页拍照（或扫描成 PDF），一次加入最多 12 个文件，程序逐张调用 GLM-OCR 识别整页文字，再自动提取其中的英语词条：

- 每行一个词条：行首的英文单词或短语（含多词短语）成为词条；支持 `/音标/`、中文释义，以及 `单词 | 释义 | 例句` 的竖线或制表符格式。
- 识别原文是 HTML 表格、Markdown 表格或两栏编号页（含 `1.` 序号、`√`/`x` 勾选标记、`belt n.带` 这类词性紧贴写法）时同样能拆出行；`belt n.` 中的词性会归入释义。
- 提取在本地完成，不需要模型；识别结果进入可编辑预览表，可直接修改或**删除**不需要的行，再导入。
- 已存在于词库的词条（含归档与回收站中的）会标记「已存在」且默认不导入；导入时也按单词去重（忽略大小写），页内重复的词自动合并。
- 表格、勾选或潦草页面如果本地拆得不理想，可点「AI 识别整理」：把整页识别原文交给已配置的模型重新提取（合并多行释义、纠正识别错误、去掉序号），结果回到同一张预览表继续核对；可取消。
- 一次最多识别 1000 个词条，超出请分批上传。

「手动粘贴」与拍照识别使用同一解析器：`单词 中文释义`、`1. 单词 释义`、`√2. 单词 释义`、`belt n.带`、`单词 | 释义 | 例句` 都可以直接粘贴导入。其他类型笔记可以粘贴截图，点击 AI 功能直接读取图片。

### 界面精简与效率（0.7.0 → 0.7.1）

- **默认进入笔记本，记住上次模式**：笔记本是这个软件的主用途，启动动画结束后直接落在笔记本（或上次离开时的模式）。
- **工具栏收敛**：顶部保留搜索、「录入」「新建笔记」与模式切换；「单词检测」移至内容列表工具栏；词汇批量录入并入「录入」，导出与旧版 JSON 导入收进「导入 / 导出」菜单。
- **详情按需展开**：编辑已有笔记时，已填写的字段照常显示，未填写的结构化字段折叠为一行「展开另外 N 个未填写字段」；新建时仍展示完整模板。
- **侧栏分组可折叠**：「笔记类型」与「按学科整理」改为可折叠分组，学科默认收起，选中学科时自动展开；列表上方的三张统计卡片已移除，计数由侧栏与标题右侧的总数承担。
- **手写笔记（0.7.1）**：新建「手写笔记」，在画布上按住书写；三种笔色、三档粗细、橡皮、撤销与清空，「加入当前页」把当前画布生成一页 PNG 原图；直接点击「保存笔记」也会保存当前手写页，与图片一样随笔记存储、可预览、可备份。
- **多选批量操作（0.7.1）**：列表上方「多选」进入勾选模式，支持全选/全不选，普通视图批量移入回收站，回收站视图批量恢复或彻底删除；`Esc` 或「完成」退出。
- **单词词典化（0.7.1）**：词条编辑改为「词头区」（单词、音标、词性同行 + 释义整行）；复习展开答案时以词典卡片呈现——大词头、音标、词性、释义、编号例句与搭配/词形/辨析分栏。
- **单词磁贴更紧凑（0.7.1）**：词汇视图的磁贴缩小为「单词 + 音标 / 词性·释义」两行式小卡，列宽更窄、一屏可见词条更多。
- **复习优先分重写（0.7.1）**：旧模型对未匹配课标知识点的笔记会塌缩到同一分数（恒为 42）。新模型以行为信号为主：到期紧迫 44%、掌握薄弱 28%、重复出错 16%、久未复习 12%，课标静态权重仅在匹配知识点时作 ±15% 微调。逾期且反复出错的笔记升到最高，刚复习过、已掌握且排期较远的降到最低；卡片与详情的「查看评分依据」给出每一项的数值。
- **加入高考考频权重（0.7.14)**：行为四项按 (1−考频权重) 缩放后，再按知识点的**考频先验**计入一档考频分——先验 ≥0.15 为「高频」（1.0）、≥0.08 中高频（0.75）、≥0.04 中频（0.5）、≥0.02 低频（0.3）、其余极低频（0.15）。高考目标取权重 **0.18**，合格考只取 **0.06**；未匹配知识点的笔记不参与考频（权重 0 取中性）。考频信号从课标微调中移出单列，避免同一信号计两次；「查看评分依据」会写出考频档位、先验值与权重。

## AI 学习功能

在左下角「笔记本设置」填写兼容 OpenAI 的模型服务地址、模型名称和密钥。地址是服务根路径（例如服务商指定的 `/v1`），程序追加 `/chat/completions`。模型密钥与 OCR 密钥独立，使用 Windows 加密存储。点击 AI 功能时才发送选定笔记；包含图片时使用支持图片输入的模型。

- 错题与普通笔记：逐步解答和学习要点。
- 物理模型：构建假设、列方程、推导结果、核对单位与适用条件。
- 解题方法：补充可复用的步骤、依据和例题。
- 英语词汇：补全词条信息。

结果单独保存为「AI 学习草稿」。核对后点击「补充到空白字段」，已有人工内容保留。资料改变后会标记草稿过期，需重新生成。生成中可取消；格式错误、响应截断、服务失败或数据被另一窗口修改时不写入结果。

## 单词检测

在内容列表上方点击「单词检测」，从有中文释义、未归档、未删除的词条中随机抽取 1–20 个。

- 看中文写英语：本地运行，无需模型；评分忽略首尾空格、大小写和英文撇号样式。
- AI 例句填空：模型生成语境，要求使用积累的原词形。

提交后显示分数、正确答案和逐项结果，并更新掌握度、复习安排与复习历史。检测期间被修改或删除的词条仅展示成绩，不写入复习记录。检测会话限时 30 分钟，一次提交有效。

## 词典查询与背诵次数（0.7.3）

列表工具栏的「查词典」只问一个词：输入英语单词或短语并回车，已配置的模型返回词典风格的音标、词性、中文释义、双语例句、搭配、词形与辨析，**词条自动存入英语词汇**，不用再手动录入。

- 查询结果以词典卡片展示，可直接「打开词条」补充语境、笔记或图片，「再查一个」继续查。
- **重复查询不新建词条**：检测到词库中已有该词（忽略大小写、撇号样式与多余空格，含归档与回收站中的），本地直接把该词条的「背诵次数」加一，不调用模型、不覆盖已有人工内容。
- 背诵次数显示在词汇磁贴（「背 N」徽标）与词条详情（复习优先分区）；新词条从第 1 次背诵开始计数。
- 释义想要更新时，打开词条点「AI 补全词条」即可重填空白字段。

## 词语关联与关系树（0.7.4）

英语词汇新增「近义词 / 反义词」字段，与原有「词形变化」一起构成词语关联：

- **来源**：词典查询生成词条时自动带上近义词与反义词；「AI 补全词条」也会补全这两个字段；也可以在编辑器手动填写——逗号、顿号或分号分隔，可夹中文注释，程序自动提取其中的英语单词或短语（词性缩写等注释忽略，每字段最多 12 个词）。
- **词条详情新增「关联树」**：以当前词为根，按近义（绿）/ 反义（红）/ 变形（蓝）三类彩色分支展开整棵关系树。词库中的词是实心节点，显示释义与「背 N」徽标，可继续展开它自己的关联，也可「打开」直接跳转编辑；重复出现的词标为「已在树中」，不会绕环。
- **词库外的关联词是虚线节点**：点「查」即走词典查询自动入库（重复查询仍只累计背诵次数），新词条自带的关联会让这棵树继续生长——查着查着，一张单词网络就铺开了。
- **通用组件**：关系树由类型注册表 + 纯图构建驱动（`desktop/renderer/relations.js`），不绑定词汇语义；将来其他笔记类型要挂关系（例如相似错题、知识点关联），注册新类型并提供关联映射即可复用同一棵树。节点上限 60，防止大词库拖慢界面。

## 自定义标签与自由布局（0.7.5）

这一版把「自由度」拆成三个互相独立的模块，各自可以单独演进：

- **自定义标签（`desktop/renderer/tags.js`）**：每篇笔记可添加最多 30 个标签——编辑器里输入后 Enter、逗号或「添加」按钮加入，标签右侧 × 移除；标签显示在卡片上（`# 标签名`），并汇总成侧边栏「标签」区块的标签云（按使用次数排序）。点击标签云按标签筛选当前视图，再点一次取消；筛选条件与搜索可以叠加，也一并出现在结果条里。标签随笔记保存、导出，搜索始终包含标签。
- **自定义侧边栏（`desktop/renderer/sidebar.js`）**：左下角「自定义侧边栏」打开配置——拖动行调整「我的学习 / 笔记类型 / 按学科整理 / 标签」四类区块的顺序，取消勾选暂时隐藏；改动即时生效并保存在本机，至少保留一个区块，可一键恢复默认。区块是注册表驱动的：以后新增区块只需注册一项，配置界面自动多一行。
- **自由布局与滑块拖动（`desktop/renderer/layout.js`）**：侧边栏与内容区之间、内容区与详情面板之间各有一条可拖动的分隔条——按住左右拖动自由调整宽度（侧边栏 170–320px，详情面板 320–760px），**双击分隔条恢复默认宽度**；「笔记本设置 → 界面布局」里可把详情面板换到**左侧**，也可一键恢复默认布局。所有布局偏好保存在本机，下次启动原样恢复；窗口过窄时自动回落到紧凑布局。
- **侧边栏条目级编辑（0.7.6）**：「自定义侧边栏」里点「编辑内容」可进入区块内部——每一项（全部笔记 / 待复习 / 单个笔记类型 / 单个学科……）都能继续**拖动排序、取消勾选隐藏**，与区块级排序叠加使用；配置同样即时生效并保存在本机。
- **笔记块自由拖动（0.7.6）**：列表里的笔记卡片可以直接拖到另一张卡上重新排列——首次拖动会自动切换到新的「自由排列」排序并记住该选择；排列位置写入数据库（随导出与备份保留），随时可切回复习优先级或最近更新。
- **侧边栏完全自定义 + 拖动改分类（0.7.7）**：侧边栏升级为**数据库驱动**——配置存进笔记本数据库（随备份与 JSON 导出/导入），与数据库侧边栏同一底层架构（数据驱动，不再依赖浏览器本地存储）。区块可**重命名**、可**新增自定义区块**（如「常用」）；「编辑内容」里条目可拖到**其他区块**改变归属，与内置区块自由混排。**笔记卡片可以直接拖到侧边栏的学科项或标签上改变分类**（换学科 / 补标签），松手即入库。旧版本地配置首次启动自动迁移。

## 物理交互仿真

在物理模型笔记内选择 PhET 仿真，点击「打开物理仿真」。支持力与运动基础、能量滑板基础、质量与弹簧、钟摆实验四项中文项目。独立窗口可调整参数、观察变化；结论可以记回模型笔记。

使用 PhET 官方在线页面，需要联网。程序没有打包或修改其源码。窗口不接入本地笔记、数据库或密钥；不提供文件下载、系统权限或新窗口。保留 PhET 页面中的署名、帮助和版权信息。[PhET 官方项目](https://phet.colorado.edu/zh_CN/)；[官方嵌入说明](https://github.com/phetsims/phet-info/blob/main/doc/phet-development-overview.md)。

## 从错题本 0.6.3 升级

使用 `Alaya-0.7.15` 升级包。可见名称、快捷方式与主程序文件均为「Alaya」（`Alaya.exe`），沿用原独立安装身份、安装目录与 `%APPDATA%\Memory Vault Mistakebook` 数据目录，其中 `mistakebook.sqlite` 保存笔记、图片、复习历史与侧边栏配置，`settings.json` 保存加密设置。0.6.4 及以上的数据库直接打开，无需再次迁移。若 Codex 的 MCP 配置仍指向旧的 `Memory Vault 笔记本.exe`，安装后在「设置与连接」重新复制一次配置。

首次打开旧版数据库时会在旁边生成 `.v1-时间戳-随机标识.bak` 快照，再迁移到 schema 2；旧记录归为错题，保留 ID、图片、时间与复习历史。JSON 导入继续兼容旧错题本；新导出含全部类型和图片。也可在设置中备份 SQLite 文件。

正式版 Memory Vault 0.6.3 和外挂可以并行安装。数据库与笔记本使用各自的数据表和数据库；既有数据库接口仍用于记忆管理，笔记本管理由独立桌面入口提供。外挂不使用正式版更新源自动安装，避免被正式版安装包替换。

## 开发与验证

`npm test` 验证核心、DSH、MCP、RPC、桌面桥接、更新和图片；`npm run test:mistakebook` 回归错题流程；`npm run test:notebook` 验证新增类型、迁移、AI 图片请求、词条本地提取、AI 词条整理、词典查询与背诵计数、词语关联解析与通用关系树、自定义标签的过滤与统计、词汇检测和结果保护。

Electron 的 `--selftest --db <临时数据库> --user-data <临时目录> --test-module tests/desktop-notebook.mjs` 验证窗口（含拍照识别单词、重复标记、AI 整理、词典查询与背诵计数、词语关联树、自定义标签、分隔条拖动与详情换位、自定义侧边栏及条目编辑、笔记块自由拖动、通用识别录入笔记），`--test-simulation` 追加官方在线仿真测试。网络测试通过真实鼠标拖动检查重力参数变化。`npm run build:desktop` 生成独立安装包。

AI 与 OCR 的请求格式、取消和失败处理以本地模拟服务测试。用户服务商的解答质量、价格及识别质量需由其实际配置决定。

Windows 打包时，构建脚本为 NSIS 卸载程序生成器继承完整环境，并使用 `desktop/dist/.nsis-temp` 作为可写临时目录。此修复仅用于构建，不改变安装后的运行参数。`tests/desktop-startup.mjs`、`desktop-loading.mjs`、`desktop-ux.mjs`、`desktop-layout.mjs` 和 `desktop-word-correction.mjs` 分别验证直接启动、静态等待、草稿及多选保护、两种窗口尺寸和追加 OCR 校对。

## 操作与界面优化（0.7.2）

- 数据库：搜索提示当前范围。编辑未保存时输入查询不会反复弹窗，按 Enter 确认；选择「保存并继续」「放弃修改」或「继续编辑」，取消后恢复原查询。刷新时放弃修改会关闭旧草稿，再从本地读取原内容。
- 保存反馈：数据库与笔记本都显示本地保存状态。数据库的已保存记录在发生修改后才启用保存按钮。编辑栏更宽，正文与整理字段分层，AI 优先级和底层约定收进展开项。
- 笔记本：录入与新建集中在顶部，单词检测与多选放在列表工具栏；搜索可一键清除，待复习、归档、回收站和无结果分别显示对应提示。详情底部固定保存与 AI 操作。
- 手写：切换学科、排序或添加图片保留笔画和工具状态；离开未保存草稿前确认。直接保存当前页不会重复加入同一张图片。
- 多选：查询更新时清空原选择，批量操作只包含当前可见条目。
- 词汇校对：追加识别保留人工修改的词形、释义等字段，取消全部勾选后禁用导入按钮。

## 架构统一（0.7.12）

这一版把笔记本并入数据库核心，成为 vault（数据库）之上的扩充，而不是一条独立的旁路：

- **统一 op 通道**：笔记本操作不再走独立的 `mistakebook:invoke` 分支，改为与数据库同一套共享 op 通道——渲染层优先调用 `window.vault.notebook(action, body)`，桥接层（`bridge.invoke`）统一分发；旧的 `window.vault.mistakebook` 调用保留为兼容入口。
- **数据层同库承载**：`MistakebookStore` 直接注入 vault 的同一个 SQLite 连接，笔记、图片、复习历史与侧边栏配置存放在 `notebook_*` 表中，与记忆数据同库。
- **布局与排序偏好入库**：侧边栏配置、面板宽度、详情位置与自由排列等布局/排序偏好全部存入数据库，渲染层不再读写 localStorage。
- **平滑迁移**：首次打开时旧 `mistakebook.sqlite` 幂等迁入 `notebook_*` 表并保留备份；对外功能、名称与快捷方式不变。

## AI 查询记录（0.7.15）

AI 侧边栏的问答不再随界面丢弃：**每一轮提问与回答都写入笔记本数据库**（独立表域，与笔记数据同库隔离），下次打开侧边栏自动恢复最近 60 条记录。

- 每条回答右下角有「**存为笔记**」：把该轮问答整理成一篇笔记——标题取问题首行，正文为「问：…／答：…」，自动打上「AI 问答」标签，可在标签云里一键筛出。
- 顶部「**清空记录**」删除全部查询记录（会二次确认），已经整理好的笔记不受影响。
- 上下文由历史重建：每轮只发送新问题与最近 39 条记录，记录即事实源，界面重开后对话可继续。

## 笔记合并与 AI 公式渲染（0.7.13）

- **手写与普通笔记合并**：不再区分「手写笔记」与「普通笔记」——统一的「笔记」类型内置手写画布（笔色/粗细/橡皮/撤销/清空、加入当前页），文字、手写页与图片同篇共存；旧手写记录打开时按笔记处理，图片原样保留。
- **AI 解答支持 Markdown 与 LaTeX**：AI 学习草稿与 AI 侧边栏的回答按富文本渲染——标题、粗体/斜体、行内代码、代码块、列表、引用、表格，以及 `\$...\$` 行内公式与 `\$\$...\$\$` 块级公式（衬线斜体近似排版，无外部依赖，符合应用的内容安全策略）。

## 更名（0.7.8）

「记忆库」模式全面更名为「数据库」：模式切换按钮、侧栏、设置与文档统一使用新名称；内部数据与接口不变，笔记本与数据库两个模式沿用同一套数据驱动的自定义架构。
