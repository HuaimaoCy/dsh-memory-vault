# Alaya 0.7.2

这是 `feat/notebook-mode` 分支上的独立外挂，保留 Memory Vault 的 Codex MCP、DSH、CLI 和本地 RPC。正式版 `main` 不包含笔记本。启动后默认进入笔记本；右上角带文字的「记忆库 / 笔记本」按钮双向切换，软件会记住上次使用的模式，下次启动直接回到那里。

## 录入与整理

点击「新建笔记」选择类型。所有类型支持标题、图片、学科、知识点、标签、检索、复习、归档、回收站及导出。

| 类型 | 可记录的内容 |
| --- | --- |
| 错题 | 题干、作答、参考答案、错因与复习建议；支持图片和 PDF OCR，校对、拆题后导入 |
| 物理模型 | 对象与系统边界、假设、变量与单位、方程、推导、适用条件、检验和应用例题 |
| 解题方法 | 适用前提、步骤、每一步依据、完整例题、误区与替代方法 |
| 英语词汇 | 单词或短语、音标、词性、中文释义、例句、搭配、词形、用法辨析 |
| 手写笔记 | 电子手写画布：多种笔色与粗细、橡皮、撤销、清空，逐页保存为 PNG 原图 |
| 普通笔记 | 知识摘录、问题、理解、学习日志及图片 |

### 录入 · 一个对话框，三条路径

右上角「录入」把所有导入收进同一个对话框，顶部三个页签按「要得到什么」切换，不再有并列的多个入口：

- **错题 · 拆题**：选择或拖入一张图片 / PDF，识别文字、校对、预览拆题后批量导入，可随每题保存整张原图。
- **整页笔记**：一次最多 12 张照片或 PDF，逐张自动识别；每一张生成一篇独立笔记草稿（标题默认取识别首行，可修改），先用「保存为类型」选择普通笔记、物理模型或解题方法，核对后批量导入，图片保留为原图。
- **英语词汇**：拍照 / 扫描积累本与手动粘贴放在同一页，上下两段，解析规则一致（见下）。

识别逐张进行并显示进度，可随时取消；单个文件失败不影响其余页面。列表上方的「导入 / 导出」菜单提供「导出笔记本 JSON」与「导入旧版错题 JSON」。

### 积累英语词汇 · 拍照与粘贴

「录入 → 英语词汇」的拍照段把整本手写积累本逐页拍照（或扫描成 PDF），一次加入最多 12 个文件，程序逐张调用 GLM-OCR 识别整页文字，再自动提取其中的英语词条：

- 每行一个词条：行首的英文单词或短语（含多词短语）成为词条；支持 `/音标/`、中文释义，以及 `单词 | 释义 | 例句` 的竖线或制表符格式。
- 识别原文是 HTML 表格、Markdown 表格或两栏编号页（含 `1.` 序号、`√`/`x` 勾选标记、`belt n.带` 这类词性紧贴写法）时同样能拆出行；`belt n.` 中的词性会归入释义。
- 提取在本地完成，不需要模型；识别结果进入可编辑预览表，可直接修改或**删除**不需要的行，再导入。
- 已存在于词库的词条（含归档与回收站中的）会标记「已存在」且默认不导入；导入时也按单词去重（忽略大小写），页内重复的词自动合并。
- 表格、勾选或潦草页面如果本地拆得不理想，可点「AI 识别整理」：把整页识别原文交给已配置的模型重新提取（合并多行释义、纠正识别错误、去掉序号），结果回到同一张预览表继续核对；可取消。
- 一次最多识别 1000 个词条，超出请分批上传。

「手动粘贴」与拍照识别使用同一解析器：`单词 中文释义`、`1. 单词 释义`、`√2. 单词 释义`、`belt n.带`、`单词 | 释义 | 例句` 都可以直接粘贴导入。其他类型笔记可以粘贴截图，点击 AI 功能直接读取图片。

### 界面精简与效率（0.7.0 → 0.7.1）

- **默认进入笔记本，记住上次模式**：笔记本是这个软件的主用途，启动动画结束后直接落在笔记本（或上次离开时的模式）。
- **工具栏收敛**：顶部保留搜索、「录入」「新建笔记」与模式切换；「单词检测」移至内容列表工具栏；词汇批量录入并入「录入」，导出与旧版 JSON 导入收进「导入 / 导出」菜单。
- **详情按需展开**：编辑已有笔记时，已填写的字段照常显示，未填写的结构化字段折叠为一行「展开另外 N 个未填写字段」；新建时仍展示完整模板。
- **侧栏分组可折叠**：「笔记类型」与「按学科整理」改为可折叠分组，学科默认收起，选中学科时自动展开；列表上方的三张统计卡片已移除，计数由侧栏与标题右侧的总数承担。
- **手写笔记（0.7.1）**：新建「手写笔记」，在画布上按住书写；三种笔色、三档粗细、橡皮、撤销与清空，「加入当前页」把当前画布生成一页 PNG 原图；直接点击「保存笔记」也会保存当前手写页，与图片一样随笔记存储、可预览、可备份。
- **多选批量操作（0.7.1）**：列表上方「多选」进入勾选模式，支持全选/全不选，普通视图批量移入回收站，回收站视图批量恢复或彻底删除；`Esc` 或「完成」退出。
- **单词词典化（0.7.1）**：词条编辑改为「词头区」（单词、音标、词性同行 + 释义整行）；复习展开答案时以词典卡片呈现——大词头、音标、词性、释义、编号例句与搭配/词形/辨析分栏。
- **单词磁贴更紧凑（0.7.1）**：词汇视图的磁贴缩小为「单词 + 音标 / 词性·释义」两行式小卡，列宽更窄、一屏可见词条更多。
- **复习优先分重写（0.7.1）**：旧模型对未匹配课标知识点的笔记会塌缩到同一分数（恒为 42）。新模型以行为信号为主：到期紧迫 44%、掌握薄弱 28%、重复出错 16%、久未复习 12%，课标静态权重仅在匹配知识点时作 ±15% 微调。逾期且反复出错的笔记升到最高，刚复习过、已掌握且排期较远的降到最低；卡片与详情的「查看评分依据」给出每一项的数值。

## AI 学习功能

在左下角「笔记本设置」填写兼容 OpenAI 的模型服务地址、模型名称和密钥。地址是服务根路径（例如服务商指定的 `/v1`），程序追加 `/chat/completions`。模型密钥与 OCR 密钥独立，使用 Windows 加密存储。点击 AI 功能时才发送选定笔记；包含图片时使用支持图片输入的模型。

- 错题与普通笔记：逐步解答和学习要点。
- 物理模型：构建假设、列方程、推导结果、核对单位与适用条件。
- 解题方法：补充可复用的步骤、依据和例题。
- 英语词汇：补全词条信息。

结果单独保存为「AI 学习草稿」。核对后点击「补充到空白字段」，已有人工内容保留。资料改变后会标记草稿过期，需重新生成。生成中可取消；格式错误、响应截断、服务失败或数据被另一窗口修改时不写入结果。

## 单词检测

在内容列表上方点击「单词检测」，从有中文释义、未归档、未删除的词条中随机抽取 1–20 个。

- 看中文写英语：本地运行，无需模型；评分忽略首尾空格、大小写和英文撇号样式。
- AI 例句填空：模型生成语境，要求使用积累的原词形。

提交后显示分数、正确答案和逐项结果，并更新掌握度、复习安排与复习历史。检测期间被修改或删除的词条仅展示成绩，不写入复习记录。检测会话限时 30 分钟，一次提交有效。

## 物理交互仿真

在物理模型笔记内选择 PhET 仿真，点击「打开物理仿真」。支持力与运动基础、能量滑板基础、质量与弹簧、钟摆实验四项中文项目。独立窗口可调整参数、观察变化；结论可以记回模型笔记。

使用 PhET 官方在线页面，需要联网。程序没有打包或修改其源码。窗口不接入本地笔记、数据库或密钥；不提供文件下载、系统权限或新窗口。保留 PhET 页面中的署名、帮助和版权信息。[PhET 官方项目](https://phet.colorado.edu/zh_CN/)；[官方嵌入说明](https://github.com/phetsims/phet-info/blob/main/doc/phet-development-overview.md)。

## 从错题本 0.6.3 升级

使用 `Alaya-0.7.2` 升级包。可见名称、快捷方式与主程序文件均为「Alaya」（`Alaya.exe`），沿用原独立安装身份、安装目录与 `%APPDATA%\Memory Vault Mistakebook` 数据目录，其中 `mistakebook.sqlite` 保存笔记、图片与复习历史，`settings.json` 保存加密设置。0.6.4 及以上的数据库直接打开，无需再次迁移。若 Codex 的 MCP 配置仍指向旧的 `Memory Vault 笔记本.exe`，安装后在「设置与连接」重新复制一次配置。

首次打开旧版数据库时会在旁边生成 `.v1-时间戳-随机标识.bak` 快照，再迁移到 schema 2；旧记录归为错题，保留 ID、图片、时间与复习历史。JSON 导入继续兼容旧错题本；新导出含全部类型和图片。也可在设置中备份 SQLite 文件。

正式版 Memory Vault 0.6.3 和外挂可以并行安装。记忆库与笔记本使用各自的数据表和数据库；既有记忆库接口仍用于记忆管理，笔记本管理由独立桌面入口提供。外挂不使用正式版更新源自动安装，避免被正式版安装包替换。

## 开发与验证

`npm test` 验证核心、DSH、MCP、RPC、桌面桥接、更新和图片；`npm run test:mistakebook` 回归错题流程；`npm run test:notebook` 验证新增类型、迁移、AI 图片请求、词条本地提取、AI 词条整理、词汇检测和结果保护。

Electron 的 `--selftest --db <临时数据库> --user-data <临时目录> --test-module tests/desktop-notebook.mjs` 验证窗口（含拍照识别单词、重复标记、AI 整理与通用识别录入笔记），`--test-simulation` 追加官方在线仿真测试。网络测试通过真实鼠标拖动检查重力参数变化。`npm run build:desktop` 生成独立安装包。

AI 与 OCR 的请求格式、取消和失败处理以本地模拟服务测试。用户服务商的解答质量、价格及识别质量需由其实际配置决定。

Windows 打包时，构建脚本为 NSIS 卸载程序生成器继承完整环境，并使用 `desktop/dist/.nsis-temp` 作为可写临时目录。此修复仅用于构建，不改变安装后的运行参数。`tests/desktop-startup.mjs`、`desktop-loading.mjs`、`desktop-ux.mjs`、`desktop-layout.mjs` 和 `desktop-word-correction.mjs` 分别验证直接启动、静态等待、草稿及多选保护、两种窗口尺寸和追加 OCR 校对。

## 启动与等待状态（0.7.2）

启动直接进入上次使用的模式，首次打开默认进入笔记本。已移除启动动画、2.4 秒展示等待与设置中的动画预览入口。AI 与 OCR 正在处理时使用静态状态文字和真实页数，保留取消、错误与完成反馈。

## 操作与界面优化（0.7.2）

- 记忆库：搜索提示当前范围。编辑未保存时输入查询不会反复弹窗，按 Enter 确认；选择「保存并继续」「放弃修改」或「继续编辑」，取消后恢复原查询。刷新时放弃修改会关闭旧草稿，再从本地读取原内容。
- 保存反馈：记忆库与笔记本都显示本地保存状态。记忆库的已保存记录在发生修改后才启用保存按钮。编辑栏更宽，正文与整理字段分层，AI 优先级和底层约定收进展开项。
- 笔记本：录入与新建集中在顶部，单词检测与多选放在列表工具栏；搜索可一键清除，待复习、归档、回收站和无结果分别显示对应提示。详情底部固定保存与 AI 操作。
- 手写：切换学科、排序或添加图片保留笔画和工具状态；离开未保存草稿前确认。直接保存当前页不会重复加入同一张图片。
- 多选：查询更新时清空原选择，批量操作只包含当前可见条目。
- 词汇校对：追加识别保留人工修改的词形、释义等字段，取消全部勾选后禁用导入按钮。
