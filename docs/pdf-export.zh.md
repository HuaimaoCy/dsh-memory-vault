# 错题 PDF 导出（自由排版）

把错题（或任意笔记）排到 A4 上，逐块拖动摆放，再导出成一份可以直接打印的 PDF。题目里的 **Markdown、LaTeX 公式与原始图片**都会保留，不是「截图拼贴」。

## 入口

- 列表工具栏「导入 / 导出」→ **导出错题 PDF…**：打开排版视图，题池是当前库里的全部笔记，之前摆过的版面会自动沿用。
- 多选模式选中若干条 → **导出 PDF**：带着这批题目进入排版视图。
- 试卷阅读页 → **导出 PDF**：试卷里的题目直接进版面（试卷本身不打印，展开成题目）。

## 排版视图

左边是题池，右边是 A4 版面。

| 操作 | 方式 |
| --- | --- |
| 加入题目 | 勾选左侧题目（再点一次取消） |
| 移动题目块 | 按住块内任意空白处拖动；方向键微调 1mm，`Shift` + 方向键 5mm |
| 改变宽度 | 拖块右侧的手柄；选中后也可用底部「占满内容宽 / 半宽」 |
| 换页 | 把块拖到另一页（松手后落到最近的页），或选中后点「上一页 / 下一页」 |
| 移出版面 | 块右上角 `×`，或选中后 `Delete` / `Backspace` |
| 撤销 | 工具栏「撤销」或 `Ctrl / ⌘ Z`（最多 50 步） |
| 缩放 | 右下 `− / ＋` 或「适应宽度」；缩放只影响观看，不影响导出 |
| 返回 | 左上返回箭头或 `Esc` |

版面设置：

- **纸张**：A4 竖版 / 横版。
- **栏数**：自动排列用 1 栏或 2 栏；块本身仍可自由摆放，不受栏位限制。
- **字号**（8–16pt）、**边距**（6–20mm）。
- **显示内容**：原图、我的作答、参考答案、错因、复盘、学科与日期、题号，逐项开关。
- **页眉 / 页脚**：留空时页眉用文档标题（如「错题 · 2026-10-25」）；页码始终在每页右下角。

## 自动排列与手工版面

- 打开时按「栏数」自动铺排：先按估算高度排一版，量出真实高度后再排一版，所以长题不会压到页面下沿。
- 拖动、改宽、微调、换页之后，这一块被记为**手工摆放**：此后改字段开关或字号只重新测量，**不会**擅自挪动你摆好的位置；工具栏「重新排列」可以随时回到自动版面。
- 还没有任何手工摆放时，改字号、栏数、边距或字段开关会整体重排。
- 提示条会如实给出「N 道题超出页面下沿」「M 处题目互相遮挡」——重叠是允许的（有人就想要压角），但不会被静默忽略。

## 导出

- 版面与设置保存在笔记本偏好里（`prefs.pdf`），下次打开沿用同一批题目与位置。
- 点「导出 PDF」→ 选择保存位置 → 主进程用 Chromium 打印成 PDF，原图按最长边 1400px 压成 JPEG 内嵌（打印够用，文件更小）。
- 上限：一次最多 100 道题、40 页；HTML 超过 64 MB 会被拒绝并提示减少题目或原图。
- 坐标一律毫米：页内位置与你看到的 A4 一致；打印用 `@page` 固定纸张尺寸，不受系统打印对话框的边距影响。

## 实现边界

- 只导出**内容**，不导出界面：版面上的块是只读的，编辑仍在笔记里进行。
- 试卷以题目展开导出；「自由画布」是另一块版面，不参与 PDF 导出（画布本版本也不支持导出）。
- 逐题覆盖字段（某道题单独显示答案）尚未提供，字段开关是整份文档统一设置。
- 打印窗口不加载 preload、不开 Node、禁止弹窗与权限请求，只渲染一份自包含 HTML（样式内联、图片 data URL、无外部请求）。

## 代码位置

| 文件 | 职责 |
| --- | --- |
| `addons/mistakebook/print-layout.mjs` | 纯几何与文档拼装：纸张、页边距、栏位、自动分页、越界与重叠判定、打印 HTML/CSS（可在 Node 下测） |
| `desktop/renderer/pdf-export.js` / `pdf-export.css` | 排版视图：题池、页面、拖动/改宽/换页、字段开关、撤销、导出调用 |
| `src/core/notebook_ops.mjs` | `notebook.export.pdf` op：选路径、调用主进程打印、原子落盘 |
| `desktop/main.mjs` | `printPDF`：写自包含 HTML → 隐藏窗口 → 等字体就绪 → `printToPDF` |

## 测试

```powershell
# 纯模型：设置夹紧、两栏几何、自动分页、坐标/宽度夹紧、阅读顺序、重叠与越界、文档 HTML 关键约束
node --no-warnings tests/pdf-layout-smoke.mjs

# 真窗口：打开排版视图、勾题进版面、切字段、改栏数重排、拖动写回毫米坐标、
# printToPDF 真出文件（校验 %PDF 头 / %%EOF / 页数与大小）、关掉再开沿用版面、空内容被拒
node --no-warnings tests/run-desktop-pdf.mjs
```

本机 Chromium 与本环境作业对象不兼容，测试进程统一加 `--no-sandbox`；测试只用 `test-tmp/` 下的一次性 profile 与数据库，不碰本机资料库。

## 两个踩过的坑

- **`run()` 开头的控件同步会把用户刚勾上的复选框抹掉**：动作读到的是旧值。修法是把「按钮态同步」与「输入值同步」拆开，`run()` 只同步按钮。
- **自动排列的第二帧（按实测高度重排）会覆盖刚拖好的位置**：重排带版本号，用户一开始拖动就作废这一帧；测试里也要等这一帧落完再拖。
