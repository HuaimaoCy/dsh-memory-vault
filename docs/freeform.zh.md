# 自由画布（笔记本）

自由画布支持手写、直接输入文字、绘制图形和引用笔记。可以随时在无限画布和 A4 竖版之间切换。

## 入口

- 侧边栏底部「自由画布」，或笔记本顶部工具栏的「画布」按钮。
- 画布打开时遮住笔记列表与编辑器，右上「回到笔记」或 `Esc` 返回；侧边栏仍在，点任一视图也会回到笔记。
- 画布打开时笔记的全局快捷键（`Ctrl/⌘ N`、`Ctrl/⌘ F` 等）不生效，不会在隐藏的笔记区里创建看不见的笔记或抢走焦点。画布自己的快捷键（`Esc`、`Delete`、`Ctrl/⌘ Z` 等）照常。

## 「无限」的含义

卡片、图形和笔迹使用画布坐标，视口可以在 20% 至 1600% 之间缩放。笔迹和图形按当前视口直接绘制。平移和缩放比例随画布保存。

## 操作

| 操作 | 方式 |
| --- | --- |
| 平移 | 拖动空白处、按住空格拖动、用鼠标中键拖动，或用 `Shift` + 滚轮横移 |
| 缩放 | 滚轮，以指针为中心，或左下「− / ＋」。在文本框或题目内容区内，滚轮滚动内容，按住 `Ctrl / ⌘` 时缩放画布 |
| 输入文字 | 点顶部文字图标或按 `T`，再点板面开始输入；也可以直接双击空白处 |
| 手写 | 点顶部手写图标或按 `B`；底部工具栏可以切换荧光笔（`H`）、整笔橡皮（`E`）、笔色和粗细；`V` 返回选择 |
| 呼出工具盘 | 在画布上右键或按 `Q`。可以换笔、切换形状、改色、调粗细、框选或撤销、重做。点画布或按 `Esc` 收起 |
| 常用颜色 | 点工具盘色块可以切换常用色、用滑杆或十六进制色值取色，并保存最多 8 种自定义颜色。手写和新图形使用同一当前颜色 |
| 框选挪动 | 点顶部栏或工具盘的框选图标，也可按 `M`。拖出矩形框住完整对象，再拖动选区。笔迹、图形、图片和卡片可以一起移动，一次拖动算一步撤销。按 `Esc` 退出 |
| 绘制图形 | 点顶部图形图标即可绘制箭头，可在工具栏切换直线、圆和正方形，或用色块选择新图形的颜色。可连续拖动绘制，按 `Esc` 或 `V` 退出 |
| 修改图形 | 退出绘制后点图形轮廓选中，再用顶部色块改色。可拖动图形，或删除、撤销 |
| 导入图片 | 点顶部图片图标选择 PNG、JPEG、WebP 或 GIF。导入后可拖动、缩放和撤销，图片随画布保存，并可随 A4 导出 |
| 移动卡片 | 拖卡片标题栏 |
| 调整尺寸 | 卡片右下角的斜纹手柄 |
| 多选 | `Shift` 点击卡片；点空白处取消选择。`Shift` 点已选中的卡片只反选，不会把它拖走 |
| 删除 | 选中后按 `Delete` / `Backspace`，或点卡片右上角 `×`。直接移除，可用 `Ctrl / ⌘ Z` 撤销 |
| 撤销 / 重做 | 顶部右侧按钮，或 `Ctrl / ⌘ Z`、`Ctrl / ⌘ Shift Z`（`Ctrl / ⌘ Y` 也行）。同一次打开白板时可跨画布撤销，编辑文字时同样有效 |
| 阅读引用笔记 | 错题直接展开题干、原图、作答、答案和错因。其他笔记可双击卡片或点眼睛预览全文 |
| 自定题目显示范围 | 用眼睛图标勾选要显示的内容。调整卡片尺寸，滚动到想展示的位置，再点「记住显示起点」 |
| 在画布中修改题目 | 点卡片上的笔图标，编辑后选择「应用到画布」。改动保存在这张卡片中，可撤销、重做或恢复原题文字 |
| 管理 A4 | 点顶部 A4 图标进入纸张模式。右下角可以添加纸张、切换当前页或移除当前页 |
| 导出 A4 | 用右上导出图标选择格式。PDF 包含所有纸张，PNG 和 JPG 导出当前页 |

手写支持鼠标和压感笔。手写工具打开时，触屏默认单指平移、双指平移和缩放；按 `Shift+B` 可切换手指书写。点击顶部手写图标或按 `V`、`Esc` 可退出手写。当前颜色默认亮蓝，普通笔默认 2 px，最细可调至 0.25 px。改色或调粗细会用于之后的笔迹。

手写和绘制图形时，圆点跟随笔尖。抬笔或暂时移到工具栏时，它留在最后的位置，并跟随当前工具的颜色和粗细。

支持 WebGL 2 的环境会用 GPU 加速正在绘制的笔画。其他环境使用分段 SVG 预览，已保存的笔迹和导出仍使用矢量路径。

A4 编辑时显示点阵。纸张默认从上到下排列，每个画布最多 24 张。移除纸张后，原位置的笔迹和卡片可在无限画布中继续使用。导出使用纸张边界和白底，PDF 按添加顺序输出 A4 竖版，PNG 和 JPG 为 2480 × 3508 像素，对应 A4 纸约 300 dpi。旧版的单张纸会自动迁移为第一页。旧画布上的便签仍可读取和换色。

## 画布管理

顶部胶囊可切换、新建、重命名和删除画布。删除后可撤销，删除最后一张时会自动新建空白画布。

## 数据位置与隔离

- 画布文档存在**笔记本域**：`notebook_meta` / `addon_meta` 的 `canvas` 键（与侧边栏配置、界面偏好同一张元信息表）。和笔记同库、同域，**不进入数据库（记忆）域的 `meta` / `entries` 等表**，也不会出现在 Codex / DSH 的记忆上下文里。
- 与数据库（记忆）UI 的独立性不变：画布代码只被 `desktop/renderer/mistakebook.js` 引用，去掉笔记本页面后数据库界面照常工作。
- 导出 JSON（`schemaVersion: 3`）带 `canvas` 段；在另一台机器导入时按画布 `id` 合并恢复（同名覆盖、其余追加），不会抹掉本机已有的画布。旧版导出没有 `canvas` 段时不动本机画布。
- 笔记本备份（`notebook.backup`）包含画布：文件模式下是整库快照；与数据库同库模式下只投影 `notebook_*` 表，因此备份里同样只有笔记本域的数据加画布。
- 旧的文件模式数据库首次迁入共享库时，画布随侧边栏一起搬家（本机已有画布时保留本机的）。

## 保存与失败

写入是 420ms 防抖的整份文档保存，右上角显示保存状态。失败时可点击状态重试，关闭前也会尝试保存。文本、图形等对象共享约 500 KB 的文档额度，笔迹另有 4 MB 的笔记本额度。

保存用编辑版本号防竞态：保存请求发出后如果又有新编辑，芯片不会提前显示「已保存」，而是保持 dirty 并在同一次 flush 里继续写下一轮（最多 5 轮，之后留待防抖重试）。因此「保存中继续打字 → 立刻切走」不会丢掉最后一批内容。

达到上限（40 个画布 / 每画布 300 张卡片 / 600 条连线）时不再抛未捕获异常，而是在底部给出可读的错误提示，画布内容保持原样。

## 读取失败与坏数据

数据库里已有 `canvas` 记录、但 JSON 损坏或结构不合法时，`MistakebookStore.canvasState()` 会返回 `{ docs, corrupted: true }`；「没有记录」是 `corrupted: false` 加空文档。`notebook:canvas load` 同时保留顶层文档字段与 `docs`，旧调用方仍能按文档解析。

渲染层看到 `corrupted` 或读取通道失败时：

- **不新建画布、不写库、不自动保存**，显示「画布读取失败」错误卡片，原数据原样留在数据库里；
- 「重试读取」会重新读一次；数据修复后即恢复原画布；
- 只有明确点「重建空白画布」并确认覆盖风险后，才会写入空文档。

这条路径专门避免旧的「读失败 → 当成空画布 → 自动建画布并保存 → 覆盖用户原画布」事故。

## 为什么新增一条 `notebook:canvas` 通道

画布只给笔记本窗口用，写入口径也只属于笔记本域。它没有进 `src/core/notebook_ops.mjs` 的共享 op 表——这样 Codex / CLI / MCP 的写入面不会因为一块 UI 版面而扩大；`desktop/main.mjs` 的 `notebook:canvas` 通道沿用同一个 `MistakebookStore` 的校验（归一化、上限、字节闸门）和同一个数据库连接，与笔记走同一份规则。

## 撤销的粒度

一次连续的文字输入、一笔手写、一次擦除拖动或一次图形操作分别计为一条撤销记录。文字输入不依赖 focus/blur 成对出现：

- 输入写入时就开一段输入会话（`writeText`），不等人先触发 focus；
- 画布重建卡片之前（`paintCards`）与任何结构性改动之前（`mutate`）先结算当前会话；
- 撤销/重做前也先结算，避免把「还没结算的输入」算进下一次撤销。

工具栏的撤销/重做按钮此前只画了图标、没有绑定点击（只有 Ctrl/⌘ Z 能用），本版本已接上 `undo()` / `redo()`。

## 本版本边界

- 每张图片最多 10 MB，每个笔记本中的画布图片合计最多 20 MB。
- 旧画布中的连线可查看、导出，也可选中后按 `Delete` 移除。
- 错题引用从笔记本读取原题，并应用当前卡片的文字修改和显示范围。A4 导出采用画布中的显示范围。
- 每次打开白板有一份最多 60 步的撤销记录，切换画布时继续沿用。
