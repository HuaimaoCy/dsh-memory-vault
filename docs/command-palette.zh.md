# 数据库命令面板

在 Alaya 的数据库界面按 **Ctrl+K**（macOS 为 **⌘K**），或点击侧边栏「命令面板」。输入关键词即可筛选新建、搜索、视图、记忆组和设置；方向键选择，Enter 执行，Escape 关闭。

- 打开和取消不修改草稿。切换视图、新建或打开设置仍经过原有未保存提醒。
- 输入法组词时不会执行命令。面板不与其他对话框叠加。
- 命令面板只作用于数据库界面，不改变笔记本的数据域或快捷键。
- 高频键盘入口不添加开合动画。
- 无匹配结果时列表保持为空，并在列表下方显示一个 `role="status"` 的提示区（「没有匹配的命令」）：读屏会读出这句提示，而不会把它当成一条可执行命令；有匹配后提示区隐藏。

## 回归测试

- `npm test`：数据库核心、桌面桥接、MCP、备份、图片等既有测试。
- `npm run test:palette:browser`：实际 Chromium 中测试面板组件；使用隔离配置目录，不访问真实数据库。可通过 `ALAYA_TEST_BROWSER` 指定 Chrome / Edge / Chromium 路径。
- `npm run test:palette`：完整 Electron 交互测试，使用临时数据库和配置目录，包含取消未保存提醒、组导航和新建后的焦点。

本机（Windows + DSH 代理沙箱）直接启动 `electron.exe` 会以 `0x80000003` 崩溃且零输出，因此 `tests/run-desktop-palette.mjs` 与另外两个 Electron runner 一样给测试进程加了 `--no-sandbox`；只作用于测试进程，安装包不受影响。

测试口径（不要把库内数据写死进断言）：

- 临时库并非空库——核心会种下「知识库」「对话记忆」两个记忆组，所以输入 `知识库` 会同时匹配固定视图与同名记忆组。`tests/desktop-palette.mjs` 先取未筛选的完整命令列表，按「label + hint 包含查询」推出应得的命令集合，再断言筛选结果**逐条等于**该集合，并额外断言固定视图排在记忆组之前（Enter 才会走视图导航）。数量与内容都断言，不写成 `>= 1`。
- 唯一探针词（含时间戳的临时记忆组名）仍用于「过滤到单条」「无匹配」两类用例。
- 未保存提醒的关闭是排队事件：`dialog.close()` 只去掉 `open` 属性，应用侧的 guard 要等 close 事件才解除忙碌，其间快捷键会被忽略。测试因此等 `#unsaved-changes` 节点真正移除，并允许 `open()` 重发一次 Ctrl+K；这不是放宽断言——焦点、ARIA 与执行结果仍然逐项校验。

组件测试不能替代完整 Electron 测试。若 Electron 自身启动失败，应保留失败记录，不视为桌面验收通过。
