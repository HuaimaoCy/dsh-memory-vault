# 错题本外挂

此功能只在 `feat/mistake-notebook-mode` 分支，主线 `main` 保留记忆库。独立程序名称是 **Memory Vault 错题本**，与正式版 Memory Vault 并行安装。

启动后点击**右上角菱形记忆库图标**进入错题本；再次点击同一位置返回记忆库。编辑中切换模式会询问是否放弃草稿。

## 录入和整理

- 新建题目：填写题干、自己的作答、参考答案、错因和笔记；可以只保留图片，之后补题干。
- 原图：支持 PNG/JPEG/WebP/GIF，每张 10 MB，最多 16 张，每道题合计 20 MB。可选择、拖入或在题目编辑器粘贴截图；点击缩略图查看大图。移除图片在保存题目后生效。
- 录入 / OCR：可以直接粘贴文字，也可以选择 PNG/JPEG 图片（10 MB）或 PDF（50 MB）。识别前在错题本设置填写 GLM-OCR 接口和密钥。
- OCR 结果不会自动入库：先校对题干、题号与公式，点击「预览拆题」，选择并修改每道题，再点击「导入选中题目」。无题号文字也会保留为一道题，不丢弃。
- 同一批次和已入库题目按完整题干去重；会忽略空白和常见字符形式差异，不按题干前 200 字截断。
- 九科学科与知识点来自用户提供的旧版 Web 资料。关键词分类是建议，仍需核对；未映射的旧知识点标识会保留并提醒重选。

## 复习

「待复习」显示未安排或已经到期的题目。打开后先独立作答，点击「展开答案核对」，再标记「做对了」或「还不会」。记录掌握度、再次出错次数和历史，分别安排后续复习。

复习优先分数沿用旧版课标量化引擎，结合知识点特征、考试目标、重复错误、掌握度和时效。部分课时/先验是旧版估计或默认值，分数只用于排序参考。

「辅助分析错因」默认使用本地规则。在设置中填入兼容 OpenAI 的模型服务后，可以请求模型建议；发送题干、作答、参考答案和笔记前会提示确认。分析建议需要核对。

题目可归档、移入回收站、恢复或永久删除。永久删除会删除其原图。

## 旧版数据与备份

点击「导入旧版」选择 JSON，支持旧版 Web 的 `records` 字典、iOS 导出的 `records` 数组和顶层题目数组。一次最多 3000 道题，文件不超过 100 MB。正确保留 `rawText/correctedText`、作答、参考答案、复习状态及归档/删除状态。

旧版 `imageAssetID/sourceRegions` 是外部文件引用，不包含图像本身；导入时会提醒补充原图，不会擅自修改旧项目。外挂自身导出的 JSON 包含原图，能够直接重新导入。

外挂数据库位于 `%APPDATA%\Memory Vault Mistakebook\mistakebook.sqlite`，独立于记忆库；不会进入 Codex/DSH 的记忆上下文。记忆模式继续读取共享记忆库，原有 Codex MCP、DSH、CLI 接口保留。模型/OCR 密钥由 Windows 安全存储加密，导出不包含密钥。

「导出」生成含原图的 JSON；设置中的「备份错题本」生成 SQLite 快照。导出与备份不能覆盖正在使用的记忆库或错题数据库。

## 本版本范围

已经提供 Windows 桌面录入、OCR 校对拆题、原图保存、知识点整理、复习、导入导出与备份。旧版 iOS 的 Apple Vision、相机扫描、自动裁题、红笔识别和 PDF 排版导出尚未移植；当前图片随每题保存整张原图，PDF 识别后只导入文字。

OCR 仅在点击「识别文字」时发送文件。本轮测试使用本地模拟服务验证完整请求、取消和加密设置，没有使用用户的付费密钥验证远程识别质量。

GLM-OCR 接口参考：[官方 GLM-OCR 项目](https://github.com/zai-org/GLM-OCR) 和 [官方版面解析配置](https://github.com/zai-org/GLM-OCR/blob/main/glmocr/config.py)。外挂不会生成主线的 stable 更新清单，自动检查默认关闭，主线安装入口被禁用；更新此外挂请使用该分支的独立安装包。
