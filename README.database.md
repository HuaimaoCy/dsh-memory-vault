# Alaya Database

**本地优先的记忆与知识库桌面端。** 全部记忆保存在本机一个 SQLite 文件里：记忆组、条目、视图、捕获、整理与备份都在这一处完成，同一份数据也能直接接给 Codex 与 DSH。

当前版本 **0.8.1Alpha**（包内版本号 `0.8.1-alpha`，Windows x64 预览版）。笔记本产品见 [Alaya Notebook](README.md)；`Alaya`（unified 发行版）同时包含两个界面并可在其间切换。

## 功能

### 记忆与记忆组

- **记忆组**：条目的一级容器，最多三层（组 → 子组 → 孙组）。在「管理记忆组」里新建、重命名、移动、切换归属与调整优先级。
- **条目**：标题、正文（Markdown 与 LaTeX 源码）、类型、标签、优先级、归属、记忆组、图片附件与可见性。
- **类型**：摘要、事实、偏好、决策、任务、笔记。
- **两条轴**：
  - *来源*：`人工输入`（你写的）与 `AI 生成`（模型写的），由系统按出处自动打标。
  - *归属*：`知识库`（跨会话复用）与 `对话记忆`（属于产生它的会话）。
- **底层约定**：长期有效的基础约定，单独一类条目，使用独立的条数与字符预算。
- **隐藏**：可逆下架——条目、标签与组全部保留，默认不出现在列表里，随时恢复。
- **知识预算**（设置 → 记忆预算）：控制提供给模型的知识条数、字符长度，以及底层约定的独立预算。

### 视图

- **内置视图**：全部记忆、知识库、对话记忆、隐藏，以及每个记忆组。
- **四种形状**：卡片、列表、表格、看板；切换形状不改变筛选与排序。
- **视图设置**：按标题、内容、标签、类型、来源、归属等条件筛选，选择排序与分组；改动即时保存。
- **可保存视图**：另存为命名视图、删除视图、恢复默认视图（内置视图回到出厂配置，自建视图保留）。
- **排序**：优先级（默认）、最近更新、按标题。

### 录入

- **新建记忆**（`Ctrl/⌘ N`）：在右侧编辑面板填写标题、正文、类型、标签、优先级、归属、记忆组与底层约定；正文支持 Markdown 与 LaTeX。
- **图片附件**：在编辑面板粘贴或选择图片，与条目同库保存、随备份一起走。
- **快速捕获**（`Ctrl/⌘ Shift N`）：一处输入，写入知识库或对话记忆，连续录入不打断。

### 检索

- **搜索**（`Ctrl/⌘ F`）：覆盖正文、字段与标签；可一键清除，结果条显示当前搜索条件。
- **命令面板**（`Ctrl/⌘ K`）：搜索视图、记忆组与动作（新建、捕获、设置、备份等），全键盘可完成。

### AI 整理

- 点「AI 整理」→ 先预览建议，再决定是否整理并保存；整理范围覆盖整个数据库。
- 需要先在设置 → AI 服务里配置兼容 OpenAI 的服务；候选内容会发送到你配置的服务，密钥在本机加密保存。未配置时该入口提示去连接服务。

### 外观与布局

- **外观**：三档界面材质——液态玻璃（倒角折射与光泽）、柔和磨砂、清晰实心；侧栏透明度连续可调并保存在本机。
- **布局**：侧栏与详情面板宽度、详情面板左右位置、折叠、专注、页面宽度、密度与预设；分隔条可拖动，双击复位，也支持键盘调整。

### 连接助手

- **设置 → Codex 与 DSH**：直接给出当前数据库的 MCP（Codex `config.toml`）与 DSH（`cordis.patch.yml`）配置，复制到对应文件即可让助手读写同一份记忆；切换数据库后需要同步更新路径。

### 设置与更新

- **通用**：查看当前数据库路径、打开其他数据库、备份数据库。
- **软件更新**：检查并安装更新（正式版与预览版通道独立）。

## 使用

### 安装与启动

1. 运行安装包，可自选安装目录；也可使用便携版压缩包。
2. 首次启动播放启动序列后进入全部记忆。
3. 要启用 AI 整理，先在设置 → AI 服务填写服务地址、模型名称与密钥；纯手工记录不需要任何配置。

### 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 命令面板 | `Ctrl/⌘ K` |
| 搜索 | `Ctrl/⌘ F` |
| 新建记忆 | `Ctrl/⌘ N` |
| 快速捕获 | `Ctrl/⌘ Shift N` |
| 保存当前编辑 | `Ctrl/⌘ S` |
| 关闭弹层 / 取消编辑 | `Esc` |

### 常见流程

**记一条记忆**：`Ctrl/⌘ N` → 在右侧编辑面板写标题与正文 → 选类型、归属与记忆组 → 保存。想长期提供给模型，勾选「底层约定」或把它放进知识库。

**快速捕获**：`Ctrl/⌘ Shift N` → 选择写入知识库或对话记忆 → 输入内容 → 连续录入（`Esc` 结束）。

**用视图整理**：在卡片 / 列表 / 表格 / 看板之间切换 → 「视图设置」里加筛选、排序与分组 → 满意后「另存为」命名视图；内置视图乱了用「恢复默认视图」。

**AI 整理**：「AI 整理」→ 预览建议 → 确认后整理并保存。建议会按数据库现状生成，可先只看预览不落库。

**备份与换库**：设置 → 通用 → 备份数据库（生成完整备份文件）；「打开其他数据库」切换到另一个 `.sqlite`，切换前会提示保存未提交的编辑。

**接给 Codex / DSH**：设置 → Codex 与 DSH → 复制 MCP 或 DSH 配置到对应文件 → 重启对应客户端。之后在 Codex 里可让模型读写成同一份记忆。

### 数据与配置

- **数据库**：默认 `%USERPROFILE%\.dsh\memory-vault\vault.sqlite`（设了 `DSH_HOME` 则为 `$DSH_HOME\memory-vault\vault.sqlite`，也可用 `MEMORY_VAULT_DB` 指定）。WAL 模式，建议整体备份而不是单独复制主文件。
- **应用配置**：`%APPDATA%\Memory Vault`（`settings.json`、更新缓存等）。
- **升级**：从旧版升级时沿用原安装身份与数据目录；数据库 schema 在打开时自动迁移，升级前建议先在设置 → 通用里做一次备份。

### 系统要求

Windows x64；AI 整理为可选项，需要兼容 OpenAI 的服务。

## 与笔记本、核心的关系

- **数据库产品**（本发行版）：记忆库的桌面窗口，只含数据库界面，不含笔记本页面。
- **笔记本产品**：[Alaya Notebook](README.md)，在同一套存储之上提供学习笔记本，界面与数据域独立。
- **核心包**（CLI / MCP / DSH 插件）：[Alaya-Database](https://github.com/HuaimaoCy/Alaya-Database)；本桌面端与它共用同一份存储格式与操作规则。
