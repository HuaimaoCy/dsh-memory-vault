# Alaya Notebook

**独立的学习笔记本桌面端。** 错题、物理模型、解题方法、英语词汇、手写与普通笔记统一收纳；数据保存在本机，界面只属于笔记本——数据库产品是另一个独立发行版，两者共用同一套存储与校验，但界面与数据域严格分离。

当前版本 **0.8.1Alpha**（包内版本号 `0.8.1-alpha`，Windows x64 预览版）。另有数据库产品 [Alaya Database](README.database.md)；`Alaya`（unified 发行版）同时包含两个界面并可在其间切换。

## 功能

### 界面

- 液态玻璃材质（倒角折射、方向性反光与中央磨砂分层），分档可退：液态玻璃 / 柔和磨砂 / 清晰实心。
- **外观**（设置 → 外观）：三档界面材质；侧栏透明度连续可调并保存在本机。
- **布局**（设置 → 布局）：侧栏与详情面板的宽度、详情面板左右位置、折叠、专注、页面宽度、密度与预设；分隔条可拖动，双击复位，也支持键盘调整。
- 分段控件支持按住鼓起、拖动放大预览、释放提交与弹簧回落；键盘操作与「减少动态效果」下保持即时反馈。

### 笔记类型

| 类型 | 记录内容 |
| --- | --- |
| 错题 | 题干、作答、参考答案、错因与复盘；支持图片与 PDF 识别 |
| 物理模型 | 对象与系统边界、假设、变量与单位、方程、推导、适用条件、检验 |
| 解题方法 | 适用前提、步骤与依据、完整例题、误区与替代方法 |
| 英语词汇 | 单词、音标、词性、释义、例句、搭配、词形、用法辨析、近义与反义 |
| 手写笔记 | 电子手写画布：多种笔色与粗细、橡皮、撤销、清空，逐页保存为 PNG 原图 |
| 普通笔记 | 文字、图片、手写同篇；支持 Markdown 与 LaTeX |

### 录入（顶栏「+」）

顶栏右上角的「+」把新建与导入收在同一个菜单里：各类型的**新建**、**编成试卷**、**自由画布**、**录入**。旁边的三个图标分别是设置、AI 助手与查词典。

- **错题 · 拆题**：选择或拖入图片 / PDF，识别文字 → 校对 → 预览拆题 → 批量导入；可随每题保留整张原图。
- **整页笔记**：一次最多 12 张照片或 PDF，逐张识别；每张生成一篇独立笔记草稿（标题默认取首行，可修改），选择保存为普通笔记、物理模型或解题方法后批量导入。
- **英语词汇积累本**：整本手写积累本逐页拍照（或扫描 / PDF），自动拆出词条（支持表格、序号、勾选标记与 `belt n.带` 这类紧贴写法），可逐行修改或删除，已存在的词自动跳过；单次最多 1000 条。
- **手动粘贴**：`单词 释义`、`单词 | 释义 | 例句` 等格式直接解析。

### 整理与检索

- **标签**：每篇最多 30 个标签，侧栏汇总成标签云（按使用次数排序）；点击标签筛选，可与搜索叠加。
- **侧栏完全自定义**：区块可重命名、新增、排序、隐藏；区块内每一项也能拖动排序或隐藏；条目可拖到其他区块改变归属。
- **拖拽改分类**：把卡片拖到侧栏的学科项或标签上，松手即改学科 / 补标签。
- **搜索**覆盖正文、字段与标签；可一键清除，结果条显示当前搜索 / 标签条件。
- **多选批量**：普通视图批量移入回收站，回收站视图批量恢复或彻底删除。
- **自由排序**：卡片自由拖动排序，位置写入数据库（随导出与备份保留），随时切回复习优先或最近更新。

### 复习与试卷

- **复习优先级**由行为加权：逾期紧迫、掌握薄弱、重复出错、久未复习四路信号，再按知识点高考考频分档计权；卡片与详情可查看评分依据。
- **单击**卡片只选中；**双击或键盘**打开整页专注阅读——左上返回，右上为 AI 查询、批注与编辑；批注与编辑结果保存到本地库。
- 把卡片拖到「待复习 / 已掌握 / 回收站」，状态写入本地库。
- **试卷编成**：1–100 道题编成一张卡片，可改名、调整题序、打开原题、拆开试卷；原题内容与复习记录保留，导入导出会重建题目引用；整张试卷可批量调整复习状态。

### 词汇与词典

- **查词典**：输入一个词，模型返回词典词条（音标、词性、释义、双语例句、搭配、词形与辨析）并**自动存入英语词汇**；再次查询同一个词不新建条目，只累计**背诵次数**（显示为「背 N」徽标）。
- **词语关联树**：近义（绿）/ 反义（红）/ 变形（蓝）三类分支展开词库关系网络——词库内的词可继续展开或跳转编辑，词库外的词点「查」即入库并让树继续生长。
- **单词检测**：看中文写英语（本地评分，无需联网）或 AI 例句填空，成绩更新掌握度与复习安排。

### AI 学习

- **AI 解答**：按类型生成讲解或补全词条，结果存为「AI 学习草稿」；核对后只补空白字段，人工内容永不覆盖；资料变更后草稿标记过期。
- **AI 面板**：从左侧展开，主界面与专注页保持相同位置；多轮对话直通已配置的模型，查询记录保存在本机数据库，每条回答可「存为笔记」（带「AI 问答」标签），也可随时清空记录。
- **批注**：专注页对当前笔记批注，结果保存到本地库。
- **Markdown 与 LaTeX**：标题、列表、表格、代码块、引用，以及 `$…$` 行内与 `$$…$$` 块级公式。

### 自由画布

- 满窗画布，底部紧凑的纯图标工具组；文本、便签、笔记引用、连线，支持平移缩放、多选、撤销与重做。

### 连接助手

- **设置 → Codex 与 DSH**：直接展示笔记本专用的 MCP / DSH 配置（`alaya_notebook`、`notebook_*` 工具），复制到对应配置文件即可让助手读写笔记本；笔记本接口只注册笔记本工具，不碰数据库的记忆域。

### 与数据库核心的关系

笔记本是数据库的**扩充**，不是平行架构：

- **底层统一**：笔记本操作与数据库操作走同一条操作通道、同一张校验表、同一个数据库连接。
- **界面分离**：笔记本界面独立，数据库界面不含它；两者互不依赖。
- **数据隔离**：笔记本数据存放于同库的独立表域（`notebook_*`），数据库的表与它互不读写；备份与导出按域切分。
- **可移除**：去掉笔记本页面后数据库照常使用。

## 使用

### 安装与启动

1. 运行安装包，可自选安装目录；也可使用便携版压缩包。
2. 首次启动播放启动序列后进入笔记本。
3. 设置 → **服务与数据**：图片 / PDF 识别填写 GLM-OCR 接口与密钥；AI 解答填写兼容 OpenAI 的服务地址、模型与密钥（密钥用 Windows 加密存储）。不配置时，录入、整理、复习、画布等本地功能照常可用。

### 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 搜索 | `Ctrl/⌘ F` |
| 新建（打开录入对话框） | `Ctrl/⌘ N` |
| 保存当前草稿 | `Ctrl/⌘ S` |
| 进入专注阅读（全屏） | `F` |
| 退出专注阅读 / 返回列表 | `Esc` |
| AI 面板发送 | `Enter`（`Shift+Enter` 换行） |

### 常见流程

**录一道错题**：顶栏「+」→ 录入 → 错题 · 拆题 → 选择图片 / PDF → 识别文字 → 校对题号与公式 → 预览拆题 → 导入。勾选「保留原图」可把整张图片随题保存。

**编一张试卷**：顶栏「+」→ 编成试卷（或侧栏「试卷」→ 新建）→ 勾选题目（最多 100 道，可上下移动调整顺序）→ 保存；之后可改名、打开原题或拆卷。

**复习**：侧栏「待复习」→ 单击选中、双击进入专注阅读 → 看完把卡片拖到「已掌握」或「待复习」；回收站里的卡片可恢复或彻底删除。

**查词并积累**：顶栏查词典图标 → 输入单词 → 查询结果自动入库 → 在词条里补充语境，或「再查一个」继续。

**专注阅读**：双击卡片（或选中后回车）→ 左上返回；右上 AI 查询 / 批注 / 编辑；`Esc` 退出全屏。

**切换外观**：设置 → 外观（材质三档、侧栏透明度）；设置 → 布局（宽度、面板位置、预设）。

### 数据、备份与更新

- **备份笔记本**：设置 → 服务与数据 → 备份笔记本（包含原图）。
- **导出 / 导入**：列表工具栏「导入 / 导出」→ 导出笔记本 JSON、导入旧版错题 JSON。
- 记忆库默认位于 `%USERPROFILE%\.dsh\memory-vault\vault.sqlite`（可用 `DSH_HOME` 或 `MEMORY_VAULT_DB` 改）；应用配置与更新缓存在 `%APPDATA%\Memory Vault Mistakebook`。
- **从旧版升级**：0.6.3 及以上的错题本 / 笔记本数据可直接升级；首次打开旧库会在旁边生成 `.v1-时间戳.bak` 快照再迁移，JSON 导入兼容旧错题本导出。
- **更新**：应用内检查更新；预览版发布为 GitHub prerelease，不影响正式版更新通道。

### 系统要求

Windows x64；AI 解答与图片识别为可选项，需要兼容 OpenAI 的服务与 GLM-OCR 接口；物理仿真（PhET）需要联网。
