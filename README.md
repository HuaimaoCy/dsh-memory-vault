# Alaya Notebook

**在 Alaya 数据库之上运行的学习笔记本。** 错题、模型、方法、词汇与笔记统一收纳；界面独立于数据库，数据域与数据库严格隔离，移除笔记本后数据库照常可用。

## 类型

| 类型 | 用于 |
| --- | --- |
| 错题 | 题干、作答、参考答案、错因与复盘 |
| 物理模型 | 对象与假设、变量与单位、方程、推导、适用条件、检验 |
| 解题方法 | 适用前提、步骤与依据、完整例题、误区 |
| 英语词汇 | 单词、音标、词性、释义、例句、搭配、词形、用法、近义与反义 |
| 笔记 | 文字、**手写画布**与图片同篇——随手记、随手写 |

## 录入

- **拍照 / PDF**：识别整页文字，校对后批量导入错题，或拆成多篇笔记草稿。
- **词汇积累本**：整本手写积累本逐页拍照，自动拆出词条（支持表格、序号、勾选标记与 `belt n.带` 这类紧贴写法），可逐行修改或删除，已存在的词自动跳过。
- **手动粘贴**：`单词 释义`、`单词 | 释义 | 例句` 等格式直接解析。

## 词汇与词典

- **查词典**：输入一个词，模型返回词典词条并**自动存入单词库**；再次查询同一个词不新建条目，只累计**背诵次数**（显示为「背 N」徽标）。
- **词语关联树**：近义（绿）/ 反义（红）/ 变形（蓝）三类分支展开词库关系网络——词库内的词可继续展开或跳转编辑，词库外的词点「查」即入库并让树继续生长。
- **单词检测**：看中文写英语（本地评分）或 AI 例句填空，成绩更新掌握度与复习安排。

## 整理与检索

- **标签**：任意条目可加标签，侧边栏自动汇总成标签云，点击即筛选，可与搜索叠加。
- **侧边栏完全自定义**：区块可重命名、可新增、可排序、可隐藏；区块内的每一项也能拖动排序或隐藏；条目可拖到其他区块改变归属。
- **拖拽改分类**：把笔记卡片拖到侧边栏的学科项或标签上，松手即改学科 / 补标签。
- **自由布局**：侧边栏与详情面板之间可拖动调宽（双击复位），详情面板可换到左侧，笔记可全屏编辑；列表卡片可自由拖动排序（写入数据库）。
- **搜索**：覆盖正文、字段与标签；可一键清除，结果条显示当前 搜索 / 标签 条件。

## AI 能力

- **AI 解答**：按类型生成讲解或补全词条，结果存为「AI 学习草稿」，核对后再补充到空白字段（人工内容永不覆盖）；资料变更后草稿标记过期。
- **AI 侧边栏**：右缘滑出的学习助手，多轮对话直通已配置的模型；**查询记录保存在本机数据库**，每条回答带「存为笔记」可一键整理成一篇带「AI 问答」标签的笔记，也可随时清空记录（已整理的笔记不受影响）。
- **Markdown 与 LaTeX**：AI 解答与助手回答按富文本渲染——标题、列表、表格、代码块、引用，以及 `$…$` 行内与 `$$…$$` 块级公式。

## 界面

- **图标即切换**：左上角品牌图标在「笔记本 ⇄ 数据库」之间切换，并记住上次的模式；启动播放 Alaya 启动序列。
- **复习**：卡片带行为的复习优先分（逾期紧迫、掌握薄弱、重复出错、久未复习四路行为加权，再按知识点高考考频分档计权），支持归档、回收站与批量管理。
- **物理仿真**：物理模型笔记内可打开 PhET 中文仿真（力与运动、能量滑板、质量与弹簧、钟摆）。

## 与数据库核心的关系

笔记本是数据库的**扩充**，不是平行架构：

- **底层统一**：笔记本操作与数据库操作走同一条操作通道（`notebook.*`）、同一张校验表、同一个数据库连接。
- **界面分离**：笔记本界面独立，数据库界面不含它；两者互不依赖。
- **数据隔离**：笔记本数据存放于同库的独立表域（`notebook_*`），数据库的表与它互不读写；备份与导出按域切分——笔记本备份只含笔记本数据，数据库备份不含笔记本表。
- **可移除**：去掉笔记本页面后数据库照常使用。
