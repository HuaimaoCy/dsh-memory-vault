材质实验台 · Liquid Glass

三个并排容器分别带 data-glass-tier，材质全部来自 glass.css。 背景是特意做重的：格子、文字、高饱和色块，用来判断模糊、斜面高光与指针光源到底有没有生效。

上排按钮改的是整页（<html>）；下面三列各自固定了自己的档位。

一、三档并排 同一套零件，只换档位

二、指针光源 引擎写 --glass-glare-x/y/o，材质只消费

三、五类表面 chrome / panel / float / hud / control

表面用在哪看什么
chrome侧栏、顶栏中等模糊、上边缘内斜面、贴边一侧的描边
panel详情抽屉、AI 侧栏与 chrome 同档，方向性高光
float菜单、命令面板、模态更强着色 + 更深投影；层级靠不透明度差
hud状态提示最轻的胶囊，不投外部投影
control按钮、导航项、搜索、分段8px 低模糊、边缘高光、悬停抬 1px、按压 .985

四、这页能验证什么 以及它不能替代什么

能验证：令牌改动后的观感、三档差异、指针光源方向、边缘高光与色散、flat 是否真的丢掉 backdrop-filter。
不能替代：Electron 里的真实窗口合成（Mica / 无边框 / Snap Layouts 都不在这里）、 高 DPI 下的细腻度、触控与键盘焦点。真机走查仍需在安装版里做。
